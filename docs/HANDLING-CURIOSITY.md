# Own-failure-led handling inquiry

This increment supplies a small motor-contrast analogy to the ordinary discovery controller. It does not invent primitive verbs, learn a general planner, explain a cause, classify a species, or establish food safety. It is separate from witnessed-consumption inquiry and heard peer teaching.

## Grounding and one paid experiment

A completed paid grasp can leave a source unacquired. Only the physical result codes for an attached, resistant or heavy object qualify, with the actor's retained matching action receipt and measured handling duration. Command rejection, full hands, inaccessible objects and interrupted work do not create this question.

The actor must also retain its own earlier successful paid pull from a different source. An aggregate success count, another actor's receipt, testimony, saved description or invented success flag is insufficient. The failed target must not already have a retained personal pull attempt or trial summary. Both sources must have fresh firsthand appearances when the failure is recognized. Exact matching of shape, color and texture is an engineered similarity prior, not learned category truth. The sources look similar now; their historical appearances are not reconstructed.

The question is deliberately uncertain: “Grasping did not acquire this. Pulling detached something from that similar-looking source. Could pulling work here?”

Behind bodily care, urgent work, existing routines and advice, the normal controller may select one pull of that exact failed source. It rechecks interaction reach for the failed target and fresh same-scene sight with matching appearances for both sources. The earlier source need only be visible, not within handling reach. It cannot approach remotely or substitute another object. Full hands, pain, exhaustion, depletion and prior adverse personal feedback block the optional trial. The physical engine still owns costs, time, capacity, ownership and finite stocks.

Selecting consumes the inquiry's opportunity, even if execution is subsequently cancelled. Any later ordinary pull of the same source also settles the pending question. The first actual canonical outcome is linked. A measured successful pull says only “detached something once”; a measured `nothing_detached` says only “did not detach”; access failure or interruption is unavailable. None establishes cause, safety, edibility or category membership.

The inquiry never selects sampling. A later ordinary sample and the actor's own delayed feedback remain necessary for nutritional learning. Generic exploration may independently try the source again; the one-shot limit applies to this inquiry mechanism, not a prohibition on all future physical actions.

## Bounded retention and persistence

Each actor keeps at most 64 non-evicting source admissions and 16 detailed questions. A repeated failure, detail eviction, restart, or changed wording cannot renew an admission. Saturation stops new handling inquiries, not care or ordinary discovery. The questions add no immortal evidence pins. If their proof ages out under ordinary bounded compaction, they retire, with references cleared but admission retained.

The current schema remains 12 and the save key remains `aincrad.world.v2`. The optional `handlingAdmissions` and `handlingQuestions` fields are checked against canonical own action/experiment receipts. Impossible links, duplicate admissions, future timestamps, extra metadata, wrong actors and completed trials rewritten as pending fail closed. Existing current saves without these fields load without invented questions. Pending questions need new runtime sightings after reload. Selected or interrupted work becomes unavailable without replay, extra material or a second debit.

The knowledge panel separately labels own handling outcomes, witnessed consumption and heard advice. Rendering and model observations are read-only projections. Strict model IPC allows only bounded IDs, timestamp, fixed question/provenance and an enumerated outcome. The optional conversation model gains no physical-action authority.

## Verification and limits

Focused fixtures arrange exposure to two distinct naturally generated sources and request the prior training pull and failed grasp. These placements are not autonomous travel evidence. The follow-up action is chosen by the ordinary controller and paid through the real action engine.

A matched selector-only ablation holds initial state, receipts, world and RNG fixed. In the fixed encounter, control inspected the target (1.8 simulation seconds, 1.68 metabolized kcal, no detached item), while the inquiry selected pulling (4.9 simulation seconds, approximately 11.091 metabolized kcal, one item detached). No sampling or food technique resulted. This demonstrates changed choice and physical acquisition in that encounter, not a general success-rate, sample-efficiency, causal-learning or survival claim.

Tests cover absent/forged/testimonial proof, source identity, fresh appearance and access, care, one-shot completion, depleted physical stock, optional-field corruption, pending/completed/selected/interrupted save continuity and proof retirement. Native desktop evidence is recorded separately from JavaScript fixtures. A source-level or JSON roundtrip pass must not be described as native close/reopen or screenshot verification.
