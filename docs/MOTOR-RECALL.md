# Exact-source motor consequence recall

A small supplied retrieval scaffold now bridges two personally paid outcomes:
“pulling detached a piece here” followed by “grasping this same source did not
acquire it.” It can select one fresh local pull to test that remembered operation.
It does not invent rules or primitive plans, transfer between similar objects,
classify food, rank methods, or promise that another piece remains available.

Only original runtime actuator witnesses qualify. Public experiment rows,
aggregate counters, saved records and another actor's experience cannot create
permission. The same actor/world/epoch/memory/physiology and original physical
source identity must persist. A successful full paid pull and a later full paid
physical grasp failure are required; full hands, range rejection, interrupted
work and sharing are not substitutes. Later contradictory/interrupted pulls
revoke remembered applicability. Actual changed stocks remain the dispatcher's
truthful outcome, not a hidden stock oracle consulted by selection.

The new path sits behind bodily care, existing routines and the unchanged
cross-source handling inquiry. It also rechecks care and identity at dispatch
and during work. It stops after one pull: no automatic sampling, food technique,
character reward or nutrition claim follows. Existing bodily effort and practice
accounting remain real. Food-learning ablation does not disable motor recall;
handling-curiosity ablation does.

The conservative full-digestion care veto is reused from handling inquiry, not inferred food benefit. Like existing handling inquiry, it uses a 300-second evidence/question window,
a 16-entry detail limit and a non-evicting 64-source admission bound. Selecting
consumes permission even if interrupted or rejected. Eviction does not refund
admission. The budget survives epoch/scene/evidence retirement on the same live actor object. Actor/scope replacement and save/reload revoke transient authority;
no new saved schema or restoration path is added. Released produced material is
not needed for a remembered source operation, but does not confer continuation
or ingestion permission. Shared custody cannot supply a personal method.

`motorRecallStatus` is a detached immutable observer projection. Reading it
cannot admit, select, expire or refresh a question. Authored tests use actual
paid grass operations with zero ingestion/effect history; these are engineering
checks, not ordinary autonomous performance or evidence of benefit/transfer.
Old cohorts and their frozen protocols are historical and are not replayed.

Historical cohort source pins are unchanged. Two source-preflight tests now
verify the literal historical hash and require the changed runtime to be
rejected by the old arm's source guard before its started marker and dynamic
runtime imports. These are negative admission tests, not cohort reruns. Neither
old activation can execute this new runtime; future ordinary validation needs a
separately reviewed new protocol and seed.
