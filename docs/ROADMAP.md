# Aincrad roadmap

## Current foundation — 0.4

- Desktop development through npm build/start/dev, following agentic-workspace.
- Original detailed pixel presentation, static idle art, wood-and-parchment interface.
- Human exploration and shared physical collision; preserved valley, river, lake, trails and three distant caves.
- Six smaller ponds, nine finite apple patches and nearby Willow Refuge; ordinary pond-side perception for new expeditions.
- Shared saved clock for day/night, seeded weather, temperature, wind, rain and food renewal.
- Ambient animals, fish and plants; apples as the first usable food.
- One persistent Aster balancing nourishment, hydration, thermal exposure and health through local perception and scene-specific remembered navigation.
- Three-apple inventory, a separate water flask, functional feelings and continuous warning/critical consequences before collapse.
- Shared procedure selection across water, food and shelter; contextual and feature values with temporal credit from actual results.
- Explicit supplied physiology, action affordances and bounded procedure-recognition templates; no arbitrary code invention.
- Gradual injuries, cause-aware collapse, partial divine rescue and retained identity, memory and acquired procedures.
- Independent NPC cave transitions and follow view; versioned migration of existing saves.
- Optional bounded local-model planning; default offline learning.

## Next research milestones

Evaluate longer unattended learning, resource renewal, reserve planning and more diverse starting conditions. Measure warning/critical time, injuries, independent meals/drinks, shelter relief and collapses across normal weather, hot afternoons, cold nights and unavailable resources. A short successful run does not prove indefinite survival or optimal route selection.

Improve procedural transfer using measured evidence and make supplied priors visible. Validate actual local-model performance separately from offline learning; Ollama's pretrained knowledge and runtime memory are distinct from model-weight training.

Further ecological interactions, hunting/fishing, player-assisted supplies/rescue, additional agents and social roles require later explicit milestones. Build a stronger single-character foundation before adding a society. Farming, construction, crafting, combat and multiplayer remain outside the current scope.
