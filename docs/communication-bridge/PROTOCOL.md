# Survival communication bridge: protocol 1

Declared before behavioral comparisons, 2026-10-28. This is an opt-in, unsaved
in-app experiment in the existing Ozark geometry, with fresh Aster and Mira.
The ordinary world remains paused and its save is untouched. Closing/restarting
the experiment discards its bodies, memories and learned weights. No trained
v1/v2 model, vocabulary, user memory, or cellular simulation is imported.

## Supplied architecture and boundaries

This is a NEW dependency-free JavaScript online learner, not the Python CNN.
The ordinary discovery/survival learner, physics, hunger/thirst, time, effort,
water and rest priorities remain active. An optional seam only selects among
already eligible, locally observed primitive experiments after bodily care.
Existing English/social/observational channels stay identically enabled in both
arms; report their activity rather than pretending this is the only channel.

The read-only sensor uses the game's actual ecology sprite projection and art
functions after personal sight/ownership checks. It supplies whole-object
segmentation, alpha-bound cropping, 16-by-16 RGB, and fixed 4-by-4 average
pooling. This is NOT learned object discovery or a full scene retina. Occlusion
is the ordinary line-of-sight gate, not per-pixel partial occlusion. Neural
inputs contain only pixels, supplied motor-channel indices, own qualitative
body channels, and arbitrary symbols. IDs/coordinates/kinds remain confined to
trusted sensing, action binding and receipt bookkeeping.

Each fresh agent has separate random sender/receiver MLPs with 16 tanh hidden
units. The sender samples one of 64 categories displayed as two base-eight
symbols; this does not impose or demonstrate compositional grammar. Receiver
scores up to eight shuffled eligible candidates with shared weights. SGD
REINFORCE, moving baseline, bounded gradients and weights are supplied learning
mechanisms. No target-identity match loss or English name assignment is used.

A supplied communication opportunity requires nearby awake actors and line of
sight. The sender's referent is its latest canonical personal ingestion effect
with a genuinely captured pre-consumption crop, at most 300 simulated seconds
old. Its own effect channels are inputs; food tables and hidden benefit are not.
The listener independently sees its own candidate crops. They need not share
an object. Each actor has at most one pending receive and one pending send;
opportunities are spaced at least 12 simulated seconds. Signaling itself has
no separate metabolic charge in this first bridge: its opportunity scheduling
is supplied, not learned motivation or cooperation. Chosen physical operations
pay ordinary time/effort and never receive shortcuts.

## Delayed reward, not survival truth

Retain the original selected active action and its paid-work witness. Link its
canonical completion receipt to one eligible ingestion: the first successful
personal sample following a selected grasp/pull/catch of its exact resulting
material, or the selected sample itself. Inspect/release/strike cannot receive
positive downstream credit. No remote report becomes personal food evidence.
No unrelated drinking, resting, metabolic drift, or later best sample is credited.

Accumulate canonical effects for that one ingestion through a fixed 60-second
simulation window. Set benefit to -1 if any discomfort occurred, otherwise 1
for sustained relief, .5 for water relief, or 0 for no effect/expiration.
Subtract min(.1, .02 * selected-action-paid-seconds / 5), then clamp to [-1,1].
Only one terminal update occurs; no early positive update before later harm.
Death, epoch/identity change, disposal or invalid binding censor the opportunity
without a reward update. Report these separately from completed windows.
The scalar mapping is an engineered reinforcement signal, not an English word
meaning. A supplied centralized trainer gives this listener-outcome reward to
both policies. It is not a learned reply/backchannel, not a sensation the sender
physically experienced, and never becomes the sender's food proof. Ordinary survival evidence is updated only by the unchanged engine.

## Comparisons and stopping

The runtime deliverable and integrity checks are the primary milestone, not a
claim of improved survival. Before results, freeze source and compare seeds
211, 223, 227 for communication enabled and constant-message control, each
600 simulated seconds, fixed .25-second maximum tick. Same world, initial
bodies, neural initialization, event scheduling rules and motor options; the
control still emits tokens but zeros message content only at receiver input.
The seed changes agent/policy randomness, not map geometry: all six trials use
one fixed Ozark world, not a randomized-world robustness test. Trajectories may
diverge from different decisions. Each fresh session is a new
learner. No warm-start, reruns for favorable seeds or post-result tuning.
Wall-time cap: 10 minutes per trial, 65 minutes total; retain incomplete trials.
Artifacts capped at 250 MiB. No paid service/GPU. Default interactive sessions
have a maximum horizon of 1,800 simulation seconds and user-controlled speed.

Report every seed/arm: simulation time, updates, attributed versus expired and
censored opportunities, sampled physical actions, own meals/drinks/collapses,
body state and conventional social-channel counts. Zero opportunities or zero
benefit are legitimate findings. A frozen read-only shuffled-message replay of
retained numeric decision inputs reports choice-distribution/argmax sensitivity,
NOT counterfactual survival improvement or proof of learning: random initial
weights can already be message-sensitive. The constant-message arm erases
shuffled content at its receive boundary and reports zero channel sensitivity. Compare body outcomes descriptively;
three pairs do not establish a general survival claim. Any scripted physical
integration fixture is labeled engineering evidence, not autonomous learning.

## Execution gate

Execution-mechanics amendment approved before any behavioral run: the available
GitHub connector does not provide workflow dispatch. The sole trigger is now
creation of the reserved branch `experiments/communication-bridge-v1-once`.
There is no dispatch path. Ordinary PR/main-push acceptance does not run the
comparison, and branch-create events do not run native UI acceptance.

After independent review and native UI gates clear, record the exact planned
commit SHA before creating that branch **once**, pointing to that verified
commit. Do not delete, update, or recreate the branch. If the create API outcome
is uncertain, inspect the branch and workflow runs before considering any retry;
never blindly repeat it. This is an execution gate, not permission to choose a
new seed or rerun favorable results. Failed/timed-out trials remain incomplete.
Any corrected source or later comparison requires a separately recorded protocol.

The job admits only the exact branch-create event/ref and run attempt 1, uses a
fixed non-canceling concurrency group, and checks out the event SHA explicitly.
Before native launch, the harness fails closed unless actual HEAD equals the
expected event SHA, the reserved event/ref and run metadata match, and the build
fingerprint equals `0797f513343ab4e3d86134ffa7eb768d5a3d2a39c2246303320fcdfc46a8d25f`.
Manifests/results retain SHA, ref, run ID and attempt. `--prepare-only` remains
launch-free and does not claim verified execution metadata.

The comparison uses fresh native processes and Canvas sensors per seed/arm.
Seeds control learner/behavior initialization; Ozark geometry remains the same.
The results include pre-disposal and terminal post-disposal snapshots so unresolved
credits are reported as censored at the 600-second boundary. Screenshots require
visual inspection; native UI integrity and policy sensitivity are not proof of
survival improvement.
