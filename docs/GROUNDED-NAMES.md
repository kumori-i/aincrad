# Grounded names for individuals

This increment concerns names for particular encountered objects. It is not a category learner, species classifier, food inference system, invented grammar, or general natural-language planner.

## What is supplied and what is learned

The simulator supplies bounded phonotactic token generation, a conservative naming preference, a pointing affordance and a small reference-check protocol. An agent's own paid encounter can lead it to choose a token for that exact individual. The lexical generator does not inspect hidden species or derive a word from the global object ID. Its random state is separate from the physical policy's random state. Two agents may choose different names for the same individual.

The learned association is personal: the chosen name, the object encountered and the evidence of that encounter. A peer's name is separate, attributed knowledge. Neither a generated token nor a repeated sentence demonstrates shared understanding.

## Local grounding and later use

A naming exchange needs awake, nearby agents with valid line of sight and current personal perception. The speaker points at an object it can actually see. The listener resolves the cue against its own current observations; no match or multiple matches produces no binding. The transport checks agreement only after that local resolution. It does not reveal unseen object identities or coordinates, teach navigation, or copy physical success.

A subsequent reference check uses the speaker's word without pointing coordinates. The listener chooses from visible individuals using its retained association. Selection and the speaker's confirmation are separate local events. A successful check means only that this listener used this speaker's word for this visible individual on that occasion. It does not establish a shared category, affordance, safety, edibility or broadly shared language.

## Memory and presentation

Chosen labels, heard-grounded labels and confirmed references remain distinct and source-qualified. Synonyms can coexist. Conflicting uses are not overwritten into false certainty, and duplicate speech does not accumulate certainty. Bounded lexical memory does not pin unlimited sensory records. A retained name cannot restore sight after reload or make an unavailable object actionable.

Each owner-name/peer pair still gets only one original pointing announcement and one original reference request. Emitting an ambiguous point or an unresolved word consumes that opportunity, including across restart. One bounded repair is now possible: only a listener actually unable to resolve a received word request may ask for clarification. The clarification identifies the speaker, token and original request, without an object identity or coordinates. Silence cannot trigger it.

The speaker may re-point once using its own remembered association and fresh sight. The listener independently resolves its current observations; no match or multiple matches creates no binding, and conflicting bindings remain conflicting. A genuinely unambiguous re-grounding permits one fresh word-only request, independent selection and confirmation. Re-pointing alone is not understanding. Clarification and re-pointing use ordinary speech cooldowns; only genuine re-grounding opens the existing eight-second, three-turn follow-up. Lost grounding withdraws acceleration but lets an already received initial request reach the listener's own resolution step.

All repair phases share the original request's 120-second deadline. Locality, line of sight, bodily safety, food handover, actor replacement or disposal cancel unfinished repair without refunding emitted opportunities. Bodies and paid actions continue; no controller hold, movement, food reward or physical learning is added. This supplied repair scaffold does not negotiate indefinitely or retry until understanding.

Strict optional mirrored repair receipts retain the consumed clarification, re-point and retry budgets independently of rotating conversation. Direction, unique identities, ordering, original-request linkage and exact cross-agent correspondence are validated; position-free clarification cannot stand in for grounding evidence. Existing valid schema-12 saves without these optional receipts remain valid.

Pending exchanges are runtime-only and clear when the application closes. Closing never completes a reference check. Independent bounded lexical evidence can survive conversation compaction, but it is validated as data, not cryptographically authenticated testimony. Corrupt current-format saves fail closed rather than silently losing conflicting evidence.

The selected agent's knowledge panel is a read-only view. Labels do not globally rename the world or transfer to detached material, carcasses, offspring or replacement individuals. Object identifiers remain available as fallback. Human Conversation aliases are not supported; the existing restricted hint grammar is unchanged. Optional model prose has no lexical or physical authority.

## Verification boundaries

Scripted encounter fixtures disclose their placement and paid interactions separately from naturally occurring behavior. Focused tests and native fixtures test the supplied mechanism, not reliable spontaneous naming, long-term society or survival. Native desktop screenshots and actual isolated close/reopen results must be reported for the architecture that ran them. A prepared harness, Node fixture test or browser rendering alone is not native execution evidence.

### Disclosed staged encounter

The native fixture selects the first physically eligible source with a uniquely resolvable pointing patch, before inspecting any lexical outcome. It performs at most four real inspections of that same individual, without changing the seed or target in response to a declined naming choice. The default fixture needed two inspections, then grounded `rulufu` for `object:496`; a separate later check confirmed the listener's use. These Node-executed fixture observations are not native desktop or natural-occurrence evidence.

An earlier first-physically-eligible placement at `object:67` produced the same chosen word but no listener binding because the pointing patch was not unique. That negative result is retained as a mechanism boundary, not converted into a successful exchange. The subsequent fixture adds unique pointing as an explicit encounter precondition rather than searching for a favorable name.
