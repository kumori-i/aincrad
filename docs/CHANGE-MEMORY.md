# Personal change memory and prospective sensory prediction

This increment remembers personally observed public before/after states linked to an existing paid action. It predicts a public outcome for an independently selected later operation; it does not choose, authorize, reward or prolong that operation. No hunting policy, nutritional value, hidden health, utility or causal benefit is inferred.

`discovery.changeMemory` is optional strict historical data: owner/world/incarnation, an independent monotonic serial, and at most16 capsules. Each capsule references the actor's existing experiment and action receipt rather than copying their outcome/cost ledger. Ordinary perception supplies appearance, motion, count, position, actor position and qualitative time/weather/shade. The two-second pre-freshness/post-window is an authored observation bound, not an empirically optimized horizon. An action-result description, naming refresh or successor ID never supplies an actual post-sighting.

Private runtime support binds capsule object/content, physical source identity/custody, actor scope and current ordinary sight. At an already chosen physical dispatch, the last two comparable-context, live-supported capsules must both be comparable and agree on the complete public outcome. Failed/unknown recent evidence blocks agreement; it is not skipped to find two favorable records. The prediction is frozen before completion, with exact support serials. Later comparison records matched, mismatched or unknown. Same-target displacement is distinct from a source-to-successor transformation: successor predictions have no source-displacement value. Even a match is a temporal association, not proof the action caused change or made useful progress. Autonomous motion remains a possible unobserved cause.

Completed handling must have the existing canonical successful paid-completion witness before a comparable observation is accepted. Cancelled/partial handling remains interrupted evidence. Missing sight, known interposition, identity replacement, self movement and environmental change cannot be negative confirmations. A later direct ordinary sight of the actual canonical successor can describe transformation, not movement of the original object.

No shared event or experiment ID is allocated. Capsules do not become proof-retention owners: dependent cleanup occurs only after the existing retention plan commits, and cannot preserve or evict other evidence. Capsule eviction never renews action authority because no action authority exists here. Raw costs remain in the referenced paid receipt; total costs of interposed activity are not attributed to the focal action.

Save validation rejects malformed present data rather than silently dropping it; absence remains compatible with existing saves. Loaded capsules are historical only. Pending comparisons and private live support are not serialized and cannot be reconstructed by copying saved records. A new ordinary action needs new runtime support for any prediction. Schema validity cannot authenticate a user-edited sensory history as genuine sight.

Authored engineering controls exercise actual paid nonfood operations, no-change predictions, changed outcomes, cancellation, own successor sight, replacement/restoration, epoch changes, save boundaries, independent serials and cap churn. A source-off control replaces only this module with inert exports and compares ordinary choice, actor/shared proofs/RNG and ecology after authored work. This is not an ordinary cohort or evidence of better decision-making, survival, hunting or transfer. Existing frozen cohorts and their source pins are untouched.

Dispatch records its own actor position and qualitative sensed environmental context without manufacturing another sight. Movement between the pre-sighting and dispatch remains confounding even if the actor returns before the post-sighting. Controller-mediated and canonical direct social requests invalidate pending comparison; actual custody handoff retires matching live support. These are negative-only hooks and do not change social action eligibility or costs.

An interposed request while paid handling is still active taints, but does not discard, that pending comparison. Only the original action’s later canonical paid receipt can complete it as unknown. A busy refusal itself creates no change capsule or paid receipt. The unknown recent capsule blocks reuse of two older concordant comparisons. Scope/identity retirement can instead remove live support; neither path fabricates completion.
